## 一、今日主题

Python 生成器进阶：执行机制、惰性求值与数据筛选。

## 二、今日学习内容

1. **生成器的执行机制**
   - 创建生成器对象时，不会立即执行函数体。
   - 调用 `next()` 后，生成器开始执行。
   - 执行到 `yield` 时返回一个值并暂停，下一次取值时从暂停位置继续执行。

2. **`yield` 与 `return` 的区别**
   - `yield` 用于生成器，可以逐个产生值并保留执行状态。
   - `return` 用于返回结果并结束当前函数。
   - 普通函数执行到 `return` 后，不会继续执行后面的语句。

3. **生成器筛选学生**
   - 使用 `for` 遍历学生数据。
   - 使用 `student["score"] >= 60` 判断学生是否合格。
   - 使用 `yield student` 逐个生成符合条件的学生。
   - 练习代码存放于本目录的 `practice.py`。

4. **列表推导式与生成器表达式**
   - 列表推导式立即计算并创建列表。
   - 生成器表达式采用惰性求值，按需生成结果。

5. **生成器的单次消费特性**
   - 生成器遍历完毕后，不会自动从头开始。
   - 再次使用 `for` 遍历已耗尽的生成器，不会输出原来的数据。
   - 对已耗尽的生成器再次调用 `next()` 会触发 `StopIteration`。
