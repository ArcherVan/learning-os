# Day 16：上下文管理器

## 今日学习内容

1. 理解 `with` 语句和上下文管理器。
2. 学习 `__enter__()` 与 `__exit__()` 的职责。
3. 理解 `__exit__()` 的返回值如何影响异常传播。
4. 编写 `Manager` 类，模拟资源获取与释放。

## 核心知识

- `__enter__()`：进入 `with` 代码块时执行，通常负责获取资源并返回对象。
- `__exit__()`：退出 `with` 代码块时执行，通常负责清理资源。
- `__exit__()` 返回真值时，可以抑制代码块中发生的异常。
- `__exit__()` 返回假值时，异常继续向外传播。
- 即使发生异常，Python 通常仍会调用 `__exit__()`。
- 资源清理与异常处理是不同的职责。
