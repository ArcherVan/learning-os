## 2. 实践内容

项目文件：`student_picker/utils/student_filter_generator.py`

实现的函数：

```python
def filter_students(students, min_id):
    for student in students:
        if student.student_id >= min_id:
            yield student
```

筛选条件：`student_id >= 3`

## 3. 理解检查

### 问题一：创建生成器时，函数体是否立即执行？

不会。调用生成器函数时会先创建生成器对象。调用 `next()` 或开始遍历后，函数体才开始执行。

### 问题二：`next()` 如何推动生成器执行？

`next()` 让生成器从当前暂停位置继续执行，直到遇到下一个 `yield` 或函数结束。

### 问题三：`yield` 和 `return` 有什么区别？

`yield` 可以逐个产生数据并暂停执行，后续可以继续；`return` 会结束函数，不能继续产生后续数据。

### 问题四：生成器相比列表有什么特点？

生成器可以按需产生数据，避免一次性创建完整结果列表。但如果需要反复访问、随机索引或重复遍历，列表通常更合适。

## 4. 遇到的问题
