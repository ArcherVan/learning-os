# Day34 学习记录：mypy 静态类型检查

## 一、今日目标

- 学习使用 mypy 对 Python 代码进行静态类型检查。
- 理解参数类型错误和返回值类型错误。
- 区分静态类型检查与 Python 运行时异常。

## 二、今日完成内容

1. 安装并运行 mypy。
2. 使用 mypy 检查函数调用中的参数类型。
3. 验证 `int` 与 `float` 参数之间的类型兼容性。
4. 验证函数返回值与返回类型注解不一致时的检查结果。
5. 完成正确代码与错误代码的对照实验。

## 三、关键知识点

- `[arg-type]`：实参类型与函数参数声明不兼容。
- `[return-value]`：函数实际返回值类型与声明的返回类型不兼容。
- 类型注解本身不会自动执行运行时类型校验。
- mypy 可以在不执行程序的情况下发现部分类型问题。
- 静态类型检查通过不代表程序不存在所有运行时错误。

## 四、实验结果

- 正确的 `calculate_total(12.5, 3)` 调用通过类型检查。
- 将字符串传入要求整数的参数时，mypy 报告 `[arg-type]`。
- `get_score() -> int` 返回整数 `100` 时，检查通过。
- 将返回值改为字符串 `"100"` 时，mypy 报告 `[return-value]`。

## 五、今日总结

掌握了 mypy 的基本使用方法，能够识别参数类型不匹配和返回值类型不匹配，并理解静态类型检查与运行时异常的区别。

后续练习中，将 mypy 应用于实际项目的函数接口，并逐步学习更严格的类型检查配置。
