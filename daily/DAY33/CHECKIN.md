## 二、今日完成内容

### 1. 函数类型注解

学习了以下语法：

- `参数名: int`：声明参数预期为整数。
- `参数名: str`：声明参数预期为字符串。
- `-> int`：声明函数预期返回整数。
- `-> float`：声明函数预期返回浮点数。

类型注解用于描述预期类型，但 Python 默认不会因为类型注解不匹配而自动拒绝函数调用。

### 2. 集合类型注解

学习了以下类型：

- `list[int]`：整数列表。
- `dict[str, int]`：键为字符串、值为整数的字典。

练习了三个函数：

- `calculate_average(scores)`：计算成绩平均值。
- `count_passed(scores)`：统计及格人数。
- `get_scores(students)`：提取字典中的全部成绩。

测试输入为 `[80, 95, 55]`，以及包含这三个成绩的学生字典。

实际输出：

```text
76.66666666666667
2
[80, 95, 55]
```

三个函数的功能测试结果符合预期。

### 3. 字典遍历

掌握了以下方法：

- `students.keys()`：获取字典的键。
- `students.values()`：获取字典的值。
- `students.items()`：获取键值对。

通过修改 `get_scores()`，理解了 `for score in students.values()` 可以逐个获取成绩，再通过 `scores.append(score)` 将成绩添加到列表。

### 4. 类型注解与运行时行为

理解了：

- 类型注解本身不会自动进行运行时校验。
- Python 是否报错，还取决于实际执行的操作是否合法。
- `len(123)` 会触发 `TypeError`，因为整数没有可供 `len()` 计算的长度。
- `add("3", "5")` 可以执行字符串拼接，结果为 `"35"`，不会仅仅因为参数注解是 `int` 而报错。

### 5. 主动运行时类型校验

编写了以下函数：

```python
def get_length(text: str) -> int:
    if type(text) != str:
        raise TypeError
    return len(text)
```

理解了通过 `raise TypeError` 主动拒绝不符合要求的数据。

进一步了解到，通常可以使用 `isinstance(text, str)` 进行类型判断，并通过异常信息说明具体错误原因。

### 6. 静态类型检查

了解了 mypy、Pyright 等静态类型检查工具的用途。

静态类型检查可以在程序运行前发现部分类型不匹配问题，例如将整数传给声明为字符串参数的函数。
