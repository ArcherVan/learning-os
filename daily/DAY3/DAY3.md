# Day 3 — 模块、导入与小程序组织

## 今日目标

把 Day 2 已练过的函数、字典和异常处理，组织成可维护的多文件小程序。

完成后应能：

- 说清楚模块、`import` 和 `if __name__ == "__main__"` 的作用；
- 把“数据处理”和“与用户交互”放进不同文件；
- 用边界数据验证函数，而不只验证正常输入。

## 练习顺序

### 1. 热身：预测输出

不运行代码，先写出下面程序的输出，并说明原因：

```python
def add(a, b):
    return a + b

if __name__ == "__main__":
    print(add(2, 3))
```

分别讨论：直接运行这个文件，以及从另一个文件 `import` 它。

### 2. 核心：拆分成绩分析器

创建两个文件：

- `score_utils.py`：只放数据处理函数；
- `main.py`：只负责读取用户输入、调用函数、展示结果。

在 `score_utils.py` 中独立实现：

```python
def analyze_scores(scores):
    """返回一个字典，包含 count、average、max、min、pass_count。
    scores 为空时返回 None。
    """
```

在 `main.py` 中：

1. 循环接收成绩；输入 `q` 时结束；
2. 非整数或不在 0–100 的值要提示后重新输入；
3. 调用 `analyze_scores`，以易读格式输出结果；
4. 用 `if __name__ == "__main__":` 启动程序。

### 3. 验证

至少验证以下情况：

- `[]`
- `[60]`
- `[0, 59, 60, 100]`

## 完成标准

- `score_utils.py` 被导入时不主动打印或要求输入；
- `main.py` 可以独立运行；
- 空列表、边界分数和非法输入都有合理结果；
- 能用自己的话解释为什么要拆分模块。
